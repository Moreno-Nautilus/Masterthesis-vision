# Python packages for /opt/thesis-venv, inside the `vision` docker container
# (Dockerfile.thesisnewcuda). This is a --system-site-packages venv layered
# on top of ROS 2 Humble's apt/system Python -- see
# external/README.md#the-venv-why---system-site-packages for why, and
# docs/setup_and_docker.md §4-5 for the full build sequence.
#
# Versions below are pinned to what's actually installed and confirmed
# working in the current `vision` container (checked via `pip freeze`,
# 2026-08-25) -- not just what Dockerfile.thesisnewcuda happens to list.
# Several of these (numpy, Pillow, PyYAML, tqdm, requests) were previously
# only ever pulled in *transitively* by other packages below and were never
# pinned anywhere -- they're pinned explicitly here so a future rebuild
# doesn't silently lose one if an upstream dependency changes.
#
# Install order (this file alone is NOT `pip install -r`-able end to end --
# torch needs a CUDA-specific index, nvdiffrast/pytorch3d need
# --no-build-isolation and come from source, and sam2 is a local editable
# install that only works once the repo is bind-mounted in):
#
#   pip install --index-url https://download.pytorch.org/whl/cu126 \
#       torch==2.7.0 torchvision==0.22.0 torchaudio==2.7.0
#   pip install -r requirements-docker.txt
#   pip install --no-cache-dir --no-build-isolation \
#       git+https://github.com/NVlabs/nvdiffrast.git
#   pip install --no-cache-dir --no-build-isolation \
#       "git+https://github.com/facebookresearch/pytorch3d.git@stable"
#   # after colcon build, with the repo bind-mounted at /workspace/MasterThesis:
#   pip install --no-deps -e external/sam2
#
# Also used as a quick repair/top-up inside an already-running container:
#   docker exec -it vision bash -lc \
#       "source /opt/thesis-venv/bin/activate && pip install -r requirements-docker.txt"
